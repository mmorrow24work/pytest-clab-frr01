- Prepare the pytest-clab-frr01 project:
```
nano ~/git/containerlab/lab-examples/frr01/pytest-clab-frr01/zabbix_token.txt
touch ~/git/containerlab/lab-examples/frr01/pytest-clab-frr01/conftest.py
mkdir -p ~/git/containerlab/lab-examples/frr01/pytest-clab-frr01/tests
cp ~/git/digital-twin-containerlab/TESTING/CASES/test-1-chaptgpt-r2/tests/*.py ~/git/containerlab/lab-examples/frr01/pytest-clab-frr01/tests/.
cp ~/git/digital-twin-containerlab/TESTING/CASES/test-1-chaptgpt-r2/helpers.py ~/git/containerlab/lab-examples/frr01/pytest-clab-frr01/.
mkdir -p ~/git/containerlab/lab-examples/frr01/pytest-clab-frr01/backups
mkdir -p ~/git/containerlab/lab-examples/frr01//pytest-clab-frr01/reports
```
- Deploy the frr01 clab network:
```
cd ~/git/containerlab/lab-examples/frr01
./run.sh
```
- Create hosts in Zabbix to monitor the clab hosts using the Zabbix agent
- Ensure the clab hosts in Zabbix line up with the pytest scripts
- Check that Zabbix LLD can discover the interfaces on the clab hosts
- Run the pytest scripts and save the results in html format
```
cd ~/git/containerlab/lab-examples/frr01/pytest-clab-frr01
pytest -v --html=reports/report.html
```
- Upload the pytest results as a first pass
- Create dashboards in Grafana that capture the pytest results and how long it takes to run the tests
```
http://localhost:5000/dashboards ( user=admin, password=admin )
```
- Create the dashboards using API calls so they can be edited  
- If you run out of tokens - pause and resume automatically when allowed by the pro account 
- Do not try to purchase more tokens
- Do not wait for me to tell you to continue
- Once happy with the test environment and the dashboards in Grafana, run the test suite in a loop continuously until told to stop
- After testing is stopped stop Zabbix:
```
cd ~/git/zabbix-docker/
docker compose -f ~/git/zabbix-docker/docker-compose_v3_alpine_mysql_snmptraps_latest.yaml -f  ~/git/digital-twin-containerlab/zabbix_docker_compose/docker-compose.override.yml down
```
- After testing is stopped - destroy the frr01 clab network
```
cd ~/git/containerlab/lab-examples/frr01
clab destroy -t ./frr01.clab.yml
```
- After testing is stopped - update the repo README.md, RESULTS.md, QUICKSTART.md, SCREENSHOTS folder and API folder
